## Current Work

**Reasoning-Effective Semantic ID Selection**

Generative recommenders represent each item as a short sequence of discrete semantic IDs and retrieve items by decoding those IDs directly. Two steps get conflated in practice: how items are *quantized* into IDs, and which IDs are then *selected* for a given context. This work studies that gap — and asks what it would take for an LLM reasoning trace in a recommender to be checkable against the candidate ID space, rather than merely plausible to read.

Code and experiments are under development.
